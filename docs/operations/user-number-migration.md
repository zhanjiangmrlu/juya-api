# 固定用户编号迁移（0019）

本次交付只本地验证，未执行云端迁移或发布。

## 编号规则

- 保留users.id及所有UUID外键；user_number是唯一、非空、正整数
- 已有用户按registered_at、id升序分配1起编号；用户列表仍保留原显示顺序
- 展示至少三位：Juya001、Juya999、Juya1000；已签发编号不随搜索、分页或昵称变化
- 新注册通过setting_counters的user_number行锁与用户创建同事务分配，重复登录不消耗编号
- AdminUser、FeedbackDetail只读新增user_code；接口路径仍使用UUID；反馈记录编号保持原样

## 未来发布顺序

1. 使用既有发布流程确认目标环境及备份，停止旧双API写进程和Worker，特别是注册入口
2. 使用已核验新镜像显式执行Alembic upgrade至0019；核对用户数、UUID及学习/授权/反馈事实不变，所有用户编号非空且唯一，计数器等于最大编号
3. 启动新双API及Worker，就绪检查须通过0019；以隔离合成账号核对新注册、重复登录与编号搜索
4. 发布配套后台；小程序更新包含新的重叠高亮显示和保持完整单词定位的查词逻辑
