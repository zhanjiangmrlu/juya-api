# Juya V1.5 Rebuild Implementation Plan

**Goal:** 完整执行已批准的句芽V1.5全量重建
**Architecture:** 统一后端代码，独立 admin/mini API 与共享领域模块；三仓四交付单元
**Tech Stack:** Python3.13, FastAPI, SQLAlchemy2, MySQL8.4, Redis/Celery, OSS; Vue/uni-app
**Spec:** docs/superpowers/specs/2026-10-17-rebuild-design.md

## Global Constraints

2核8GB ECS，20并发初始目标；测试生产数据配置隔离；清理仅精确列举的句芽资源；秘密不入仓库；草稿和发布隔离；学习三类记录同事务；二导航；无历史迁移。

## Review Focus

- 午夜后重放同幂等请求仍归原日期；并发不同卡片同一天只一打卡
- 下线/删除/换版后旧资源请求、旧预览和旧写入被拒绝
- 已保存联系清空与并发资料覆盖必须失败；空联系方式不限制学习
- 任务投递失败/worker重启可恢复，批量成功项不得重做
- 独立发布管理API不重启mini API；迁移保持运行版本兼容
