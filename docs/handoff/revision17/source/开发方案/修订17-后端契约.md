# 修订17后端契约

需求真源：`../../requirement-reference.json` 第35—40章。2026-10-28已实现接口；以下为实际新增契约，机器契约位于 `project/juya-api/openapi/{admin,mini}.json`。当前迁移头0022，服务ready最低0022；原场景API保持兼容。

## 通用

管理员沿用Cookie + X-CSRF-Token，学习者沿用Bearer。全部写入需要16—128字符 `Idempotency-Key`，同键同参数重放结果，改参数409。分页 `{items,total,page,limit}`，page从1开始，limit≤50。错误沿用 `{error:{code,message,details},request_id}`。版本冲突409，不静默覆盖。ID为稳定UUID。时间UTC ISO8601；打卡日北京时间。

新增前缀：管理 `/api/admin/v1/listening`，小程序 `/api/mini/v1/listening`。无M确认时 `access.reason=listening_not_open`，即使授权有效也不开放听读；不影响场景。正文偏移用原文Unicode code point偏移；客户端JS需转换UTF16位置。

## 文章资料

`payload={title_zh,title_en,tags:string[],body_en,translation_zh,expressions:[{english,chinese,example}],word_meanings:[{start,end,word,lemma?,phonetic?,chinese}],audio_id:string|null,image_id:string|null}`。
双标题、正文、译文默认空；tags/expressions/word_meanings默认[]；草稿允许缺项。发布要求归属有效、双标题正文译文非空、恰好5组完整表达、音频ready且可播放。原图可空。`word_count`服务端按英文词项自动算，撇号与词内连字符合并。

文章管理对象 `{id,topic_id,status,revision,version_id,topic_order,global_order,payload,word_count,timeline,created_at,deleted_at,draft_topic_id,draft_topic_order,published_topic_id,published_topic_order}`。管理topic_id/topic_order返回当前编辑稿归属，published_*明确表示原发布归属；draft_*只在待发布迁移主题时非空。保存改主题不改变用户正在读取的列表/进度/下一篇归属，明确发布才切换。revision用于所有修改的乐观锁，排序变化会递增受影响文章revision；version_id仅在明确发布时变化，非正文变化不重置版本进度。status=draft/published/offline/deleted。
安全摘要 `{id,content_type:'listening',topic_id,title_zh,title_en,tags,word_count,version_id,available,thumbnail_url,access,state}`；受限不含正文、音频或原图，只允许受控小缩略图；下线/删除thumbnail_url=null。`state={favorite,completed,today_completed}`。
摘要还包含可空 `favorited_at,first_completed_at,last_completed_at,completed_at`；favorites填真实收藏created_at，records填首次/最近完成时间，每日明细填当日Daily.accepted_at为completed_at。不能把最近完成时间当作收藏或当日完成时间。
`access={can_learn,can_lookup,is_free,reason,server_now,expires_at,version}`；lookup始终要求现有统一学习授权有效。

`progress`无同发布版本记录时返回初始值，绝不自动播放。`timeline={state,input_hash,job_id,words,reviewed_at,error_code}`，state=pending/processing/ready/needs_attention/failed/missing；ready自动启用，与reviewed_at无关。words只在匹配当前正文音频且ready时返回，原文偏移与音频毫秒。
自动校验默认要求正文词覆盖1.0，词间保留实际静音间隔，单词最大时长默认10000ms可配置。独立持久DB队列入口 `python -m juya_api.listening_worker [--once]`，保存/暂存自动排队。腾讯识别前生成保持完整时长的16kHz单声道32kbps专用副本，不修改原始/播放媒体；仍超官方5MB输入限制时真实失败，不裁音频或均分时间。已接受云task ID持久保存后轮询，未知响应不重提；进程死亡于提交窗口且无task ID时needs_attention/asr_submission_unknown，需先核查服务商任务。已知权限拒绝返回asr_permission_denied；真实外部ASR尚未业务验收。

### 既有后台用户/统计增量字段

原 `/api/admin/v1/users`、`/users/{id}` 的 statistics，以及原小程序 `/api/mini/v1/me/statistics` 增加 `completed_articles,today_completed_articles,listening_favorite_count`，原completed_cards/favorite_count只计场景；原 `/api/admin/v1/statistics` 增加 `published_article_count`。既有checkins列表增加article_count，共享同一打卡日。新增管理前缀下 `GET /users/{user_id}/records?page&limit` 查询本人听读已学分页，`GET /users/{user_id}/checkins/{day}` 返回两类明细 `{date,scene_items,article_items,card_count,article_count}`。

| POST /imports/{id}/preview | `{revision,candidate_ids:string[]}` | `{preview_token,candidate_ids,counts}`；不保存草稿 |
| POST /imports/{id}/save | `{preview_token}` | `{batch,items:[{candidate_id,status,article_id?,error?}]}`；成功/跳过保留，失败可单独重试 |

批次候选 `{id,package_id,path,state,payload,topic_id,errors,article_id,duplicate_of,removed,timeline}`。state=complete/incomplete/unreadable/duplicate/saved。同资料（文档内容及关联素材哈希）去重；标题相同不同资料不跳过。暂存/文章共用输入hash时间轴，候选移除后旧任务失效，已保存草稿不被候选移除删除。
