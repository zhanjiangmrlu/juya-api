# 暂停学习授权与内置查词

用户于 2026-11-11 确认：所有用户（包括授权有效账号）只可学习已发布且明确标记免费的内容。非免费内容保留列表和安全摘要，受保护接口返回 403 / `content_not_open`，文案“暂未开放”。授权记录、后台维护接口、原权限分支保留，不迁移或清理数据。

## 代码开关与契约

`src/juya_api/learning_features.py`：

- `LEARNING_AUTHORIZATION_ENABLED = False`：有效授权不再增加学习权限
- `IN_APP_DICTIONARY_ENABLED = False`：所有账号正文内置查词关闭，受控查词返回 403 / `lookup_unavailable`
- `permission_mode()` 进入场景及听读 `access.version`，模式切换使旧权限快照失效

响应结构不变，`reason` 仍为开放字符串。暂停期间 `can_lookup=false`、`expires_at=null`，避免原授权到期影响免费内容。非免费内容仍保留安全缩略图、收藏和学习历史，不开放正文、全文音频、原图、学习笔记及预置词发音。媒体票据 GET/HEAD/Range、学习写入、下一篇及继续学习复用实时权限判断。分类受限篇数不再因有效授权归零。

恢复时修改上述对应代码开关，并与小程序 `src/shared/constants/learning-features.ts` 对应开关一起发布；保留分支有显式 `legacy_learning_features` 测试夹具覆盖，默认夹具不会打开功能。恢复前同步修订接口字段说明。后台授权维护不受此次暂停影响。

## 配套小程序与验收

账号学习授权区域和专用请求暂停，学习授权提示隐藏或改“暂未开放”；登录和隐私同意保持。正文内置词典和预加载暂停，支持系统选词复制。主题听读动态高亮、尾迹与自动滚动暂停，静态重点色带、播放和进度保存保留。
