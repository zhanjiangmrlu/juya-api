## T64／T77专项：只读不是“所有请求都是GET”

Admin `ScenePreview`仅`mode === 'draft'`显示确认发布，`mode='published'`为关闭预览；`SceneReader`的收藏与完成是disabled展示，不引用Mini写接口。用户记录通过`/api/admin/v1/cards/{id}/published`取当前发布版，传`version_id`到管理员受控试听。草稿、导入、已发布试听可能合法POST管理员发音任务；不能把这种POST当成用户完成/收藏/打卡，也不能为了“只读”禁掉批准的管理员试听。
