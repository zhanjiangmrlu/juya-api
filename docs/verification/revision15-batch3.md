范围：需求第33章、T169—T178。两角色独立鉴权，本地开发与隔离合成验证，没有推送、部署或修改真实学习数据。

## 实现

- 四分类、每次1—500 Unicode codepoints、0—3图；原说明与无限次补充保留同一时间线。用户任何状态追加后回待处理；管理员普通回复不改状态，要求补充／已处理需对应说明。
- 主记录、事件、双方独立读水位与截图四表，增量迁移0015。事件在反馈行锁内分配顺序；慢安全检查之后取接受时间，更新时间不倒退；截图按用户选择顺序保存。
- 所有提交采用持久幂等，已成功回执先恢复，安全服务后续故障不影响旧成功结果。未知结果先查原操作；历史回执确认后重新读取当前时间线，不用旧状态覆盖新事件。
- 图片真实解码、限制静态类型及像素、去元数据、最大2048压缩、私有保存。原生图片使用5分钟用途／角色／会话绑定grant，读取再查归属、会话与附件事件；过期续签不重传成功图。
- 文字加密保存，后台授权摘要搜索不建明文内容索引。真实HTTPS安全网关仅最终allow通过，pending／review／失败／未配置明确拒绝并保留输入；工厂测试替身不进入生产默认。
