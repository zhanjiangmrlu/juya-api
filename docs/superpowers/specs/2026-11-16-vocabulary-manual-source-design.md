# 所有格与人工来源修正

用户明确要求：名词所有格's自动匹配；系统未匹配的词允许人工选择真实正文片段，不能再次被自动匹配否决；待人工补充条目标红。沿用现有test基线和已有隔离工作树，修改API、后台及两前端生成契约。

采用扩展共享匹配规则并独立验证人工确认来源的方案。只修改自动规则无法解决未知词形的人工兜底；取消所有来源校验会接受伪造或过期位置，因此仍校验当前正文和坐标。Source/VocabularySource增加可选manual_english，人工选择时记录当前词条英文，服务端核验同词条及当前真实片段后保留；旧自动来源无该字段，规则不变。正文或词条变化使人工来源失效时重新核对。自动匹配不擅自确认未知词。

场景偏移为UTF-16，听读为Unicode码点。自动识别直/弯引号所有格，展示完整原文词形（例如vine's）；不误配子串及无关词。人工选择覆盖过期资料原句提示，并可分别保留同词不同义。没有人工操作或不合法片段继续阻止发布。选填/必填、附件、权限和暂停开关保持。

后台待核对的词条卡片、来源框和汇总行采用既有危险色、浅红底及文字，人工确认后显示“人工已确认”。听读选择原句的临时状态在自动预览期间保留，选择实际词形后才标记确认。无需数据库迁移。

用户在短暂暂停部署后明确要求结合其他对话推到远程test的内容一起部署，并再次确认改完即可部署测试环境，作为本轮发布授权。固定组合源码、官方CI、备份/无迁移、7服务及站点验证见docs/verification/vocabulary-manual-source-20261116.md。本次没有数据库迁移，小程序仅契约变化、不改运行代码，不重复上传。
