# CHG-0039 本地整改验收

用户确认清空历史数据暂留空列；本轮只在三仓本地test开发并验证隔离数据，没有操作真实业务数据或远程环境。最低schema0026、数据库contract3维持，CLI无改动。

## 行为和接口

- PATCH /api/mini/v1/me/contact：有效身份统一410/contact_collection_disabled，不解析联系正文或幂等头，不写入也不重放旧成功；未登录401
- UserProfile及登录、本人资料/保存、后台列表详情删除phone/wechat_contact/phone_source/wechat_source/contact_version；编号昵称搜索与真实total保留
- 联系回执查询410；资料回执与两处登录重放都按当前用户资料白名单过滤，清理前也不泄露
- 清理工具默认dry-run，显式目标确认后apply；失败批回滚并立即停止，可重试，计数脱敏；非空但缺失user的登录回执同样失败停止
- 小程序保留旧路径跳转壳与收藏入口；退役本地联系待确认任务与埋点。隐私删除自愿联系收集条款，保留统计披露及同意逻辑
- 后台移除联系展示/来源，空结果保留八列表头、筛选、清空入口及分页
