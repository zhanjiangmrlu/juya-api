# 修订15批2：正文查词与受控发音验证

验证范围：T160—T168。仅本地合成账号／素材，没有推送或部署。

## 实现与证据

- API 独立核验当前发布卡片、版本、正文行及 UTF-16 起止位置；任意文本／伪造位置拒绝。上下文释义只按明确位置匹配，缺省才回退通用词典；原词、原形与实际读音目标分开。
- 通用词典为明确配置的本地 JSON 适配层，未配置／损坏与真正没有词条分别返回。生产代码没有内置合成词库；provider/license 字段不等于已经审计授权。
- 小程序正文完整词可点，弹窗分别展示本篇／词典、原形、无音标、未找到、加载及错误，保留重点词汇与整卡收藏。切换／关闭使迟到查询及发音失效。
- 独立只读审查两仓差异未发现 P1／P2。后续针对 Unicode 大小写匹配边界补充回归，避免前后端规则分歧。

## 实际本地链路

使用隔离 SQLite、实际两角色 API、实际 H5 和独立合成词典，端口 18195／18196／4185。合成词库不是生产数据源。

- 十个实际 HTTP 释义查询覆盖 emoji 前缀／UTF-16、went→go、don't、take-away、U.S.、重复 coffee／mobile、两个 read 的 red／read 读音目标、xyloword 无结果；伪造词 422，匿名 401。
- H5 显示 went 原词、go 原形及本句释义且不借用 go 的音标；第二处 mobile 显示“能自由活动的”；don't 标为词典释义；xyloword 明确无结果。
- H5 真实 30 秒合成音频播放时点词，整篇继续；点弹窗喇叭后整篇停在 0:19。未配置真实 TTS 时，实际任务返回“发音暂不可用，点击重试”。关闭弹窗仍保持展开译文及 0:19，须手动继续。
- 页面截图及无凭证结果保存在工作区 `.private/revision15-verify/`：`batch2-context-lemma.png`、`batch2-context-position.png`、`batch2-missing.png`、`batch2-voice-error.png`、`batch2-api-results.json`。

## 验收边界

组件／服务测试覆盖迟到响应、关闭停止、词边界、长内容及受控发音引用；H5 不能替代微信原生音轨／倍速／弹窗滚动的 iOS／Android 真机验收。实际授权词库覆盖与词形覆盖、腾讯云语音质量、真实 MySQL 环境另列待验收，不以合成词典／静音音轨代替。
