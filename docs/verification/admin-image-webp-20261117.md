# 管理后台图片压缩与 WebP 转换

本地基线为 test 的71557cc，在隔离分支codex/admin-image-webp实施。远程SSH读取失败，未声称已验证远程最新状态。未推送、部署或改动原运行服务/账号/业务数据。

## 行为

场景新增/编辑、独立DOCX配图、ZIP包内图片，以及听读新增/编辑、DOCX配套图片和ZIP，统一在服务端写入独立图片对象前处理。原文件严格大于1048576字节时转为真正WebP；quality85优先、最低80，仍超限则保持80等比缩小。小图逐字节保留；透明通道及EXIF方向保留。继续执行原10MB输入上限、静态PNG/JPEG/WebP及20MP限制。

原ZIP保留作为导入来源，不重新打包；浏览器向API传输的仍是原文件。本次处理的是解出的独立图片和直接图片上传，不修改DOCX/PDF内嵌图、历史图片、头像或反馈图片。

## 存储与兼容性

0030增量迁移仅增加media.source_sha256可空列及索引，无历史回填。Media.sha256/size验证实际存储字节；source_sha256用于转换前原图去重。旧媒体回退使用原sha256。ImportFile继续展示来源原始大小和摘要，storage_key关联处理后媒体，不重复保存单张原图。请求幂等指纹仍基于原请求字节。

最低schema30，code contract3；公开OpenAPI无需改动。未来发布须先备份并迁移数据库，再更新API及worker；本轮仅在隔离测试库执行迁移，原本地与远端数据库未迁移。
