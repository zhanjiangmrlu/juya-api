## 根因与修复

生产 IELTS B2-C1 分类有 322 篇，冻结队列凭据约 17.6KB，被放进 GET URL 后约 17.7KB。2026-11-18 北京时间 20:50:12.439 已保存本篇完成事实，20:50:12.493 获取下一篇在 Nginx 返回 414，后续重试重复失败。等长无凭据模拟请求也返回 414；较短请求到达应用并返回正常 JSON 401。

新增只读 POST `/api/mini/v1/listening/articles/{article_id}/next`，通过 JSON `queue_token` 传递原凭据，直接复用旧 GET 的查询、账号/签名/有效期/分类检查及逐篇实时权限判断。保留旧 GET；无数据库迁移、缓存依赖或学习写入。新输入和操作中文说明已加入 OpenAPI，并同步小程序契约和生成类型。

小程序使用 POST 查询，单独重试不重复提交已确认完成。打开下一篇改为只携带文章 ID，原冻结队列经内存一次性交接，绑定当前会话身份和目标文章；消费后清除，导航失败清除，账号变化拒绝使用。旧页面显式携带队列时保留原有解码与语义。内存交接丢失（如进程重新启动）时，从详情建立新队列。
