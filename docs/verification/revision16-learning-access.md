## 独立最终审查与修复

独立审查报告0项Critical、5项Important、0项Minor。五项均接受，在一次修复轮次内建立失败回归并修复，随后重跑上述完整套件：

1. 大图onLoad/onShow重复权限请求导致初始图片被废弃：共享在途检查，生命周期合并请求；实际组件初始图片回归先失败后通过。
2. A06等待预览时切换操作导致确认内容错配：冻结操作/日期，等待时禁用切换，舍弃过时响应；延迟响应回归先失败后通过。
3. 缓存词典发音、音频进度/倍速变更可能跳过权限复核：交互前刷新权限、撤销后阻止旧缓存播放；缓存撤销回归先失败后通过。
4. 权限读取失败仍展示保护正文、允许新完成：权限未知时遮蔽正文和新学习操作，保留恢复入口；未知状态回归先失败后通过。
5. 回到前台跨日或发布版本变化仍沿用旧详情：应用服务端安全学习状态、更新当天提示、清理旧正文/分享/媒体和预取；跨日及版本变化回归先失败后通过。

附加收尾：A05末页因状态变化被服务器夹取后同步URL页码；新增回退用例先失败后通过，既有返回筛选/滚动测试继续通过。无延期Minor项。
