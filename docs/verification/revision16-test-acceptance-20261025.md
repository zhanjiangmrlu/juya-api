2026-10-25（北京时间）。本轮核验免费场景、开通、续期、自定义到期、撤销、到期回收及相关资源权限。公网业务断言 **62/62 通过**；隔离真实 MySQL 专项 **32/32 通过**；后台 **169/169**、小程序 **334/334** 自动回归通过。后台实际点选操作与微信开发者工具模拟器检查完成。体验版真机及真实跨午夜仍未验收，不能据此认定所有端到端场景全部通过。

本轮未发现可复现的业务缺陷，未修改或重新发布业务代码。新增四个专项测试用例：跨10条后台分页、排序使旧免费确认失效、跨年、闰日续月。

## 环境与方法

- 后台：[测试后台](https://test-admin.juyayingyu.com)。管理接口：[管理接口就绪检查](https://test-admin-api.juyayingyu.com/health/ready)。小程序接口：[小程序接口就绪检查](https://test-api.juyayingyu.com/health/ready)。两接口实际返回 `environment=test`、`status=ready`，角色契约及匿名/跨角色拦截通过。
- 测试服务沿用已发布 API `650c022`、后台 `1e86b6e`；本轮无重建、重启或部署操作。微信体验版 `1.5.0-test.1025.1` 的设置状态沿用用户确认，未独立读取平台状态。
- 公网测试在 `juya_test` 建立专用账号“验收专用1025”，通过限定该用户的 SQL 夹具建立短期身份会话，然后实际调用公网 HTTPS 接口。该身份准备不能证明真实微信登录交换已通过。
- 管理员通过正常登录、Cookie、CSRF、预览确认及幂等键操作。后台另通过浏览器真实点选开通、续期、取消撤销、确认撤销，并查看审计。
- 到期回收采用专用账号过期数据：仅将该账号到期日设为前一天并增加修订号，再通过公网验证。未更改服务器时间，也未将这项验证称为真实跨午夜。
- 月底、闰年、跨年、午夜前后一秒、并发和迁移在独立本地 MySQL 8.4.13 数据库 `juya_verify` 验证，测试套件从未连接 `juya_test`。相关用例使用受控时钟，外部微信交换及素材提供方使用测试夹具；这部分不等同于公网或真机验证。
- 模拟器使用当时已打开的 `dist/dev/mp-weixin`，实际配置指向测试接口，包含后续字体改动。它验证的是开发构建，不是已上传体验包的真机运行。

## 发现的问题和处理

1. **测试环境原本未启用免费规则。** 这是待确定 N 的配置状态，不是功能失效。验收临时使用 N=1、0、999，完成后恢复 `enabled=false`、`free_count=null`。现在要在体验版看到限制，仍需管理员填写业务确定的 N、核对名单并保存。
2. **微信开发者工具出现一次系统路由错误。** 进入账号页时记录 `routeDone with a webviewId 18 is not found`，调用栈为微信基础库；当时开启自动热重载。随后账号返回、学习页刷新、受限提示、免费详情、播放、点词提示及译文操作均成功，错误数未增加。尚未证明根因，也未复现为持续业务故障，因此没有猜测性修改业务代码。体验版真机复核保留为未验收项。
3. **验收覆盖缺口已补足。** 增加跨10条后台分页、排序后旧确认失效且成绩保留，以及跨年/闰日用例，共新增4个用例，真实 MySQL 运行通过。业务实现无需修改。

原始私密执行日志保留了验收脚本自身的字段名、收藏计数比较范围、审计条数预期修正；这些不是产品缺陷。最终断言清单62项全部通过，失败记录另存，未篡改原始日志。
