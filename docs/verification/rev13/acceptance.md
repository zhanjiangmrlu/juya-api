# CHG-0015 开发与验证记录

日期：2026-10-18。依据独立增补需求 N01—N29，Figma「个人主体微信登录·修订13」指定的21个画板。三个仓库沿用稳定卡片ID和不可变发布版本，当前工作分支均为 `codex/bilingual-audio-rev13`。

## 本批实现

- 中文仍使用唯一规范字段 `name`，独立新增 `title_en`，避免重复中文列产生分歧；历史JSON读取时补空英文，不改写历史版本或哈希。列表、详情、收藏、记录及批量操作回执同版本返回两种标题。
- DOCX只从当前H1范围、首个内容H2之前的正文元信息读取英文标题。缺失可存草稿；冲突保留可读正文并明确提示。单卡DOCX需核对并明确确认双标题及文本替换，图片和完整音频引用保留。
- 多ZIP沿用原有受控队列、包实例与目录隔离、回执查询及分项重试；不根据标题或文件名推断更新目标。示例DOCX/ZIP和说明已更新。
- 四类音频按真实格式完整解码，原件字节、来源、校验和不变；非MP3生成确定ID的完整MP3副本，合格MP3复用原件。仅原逻辑素材通过鉴权后可解析至播放副本，支持Range。长静音/VBR AAC的时长采用完整解码时间戳，避免ADTS容器估算误报。转码失败保留原件，重试复用阶段与副本ID。
- 迁移前历史音频不会自动批量改写。重新发布前必须有就绪MP3；编辑页可明确发起兼容处理，重复点击复用任务，处理期间保留原发布版的播放访问。
- U03五档倍速由真实播放器执行；会话内跨场景保留，暂停切换不自动播放，词汇正常速度且不自动续整篇。失败显示错误并保留已生效档位。H5使用HTMLAudioElement适配，微信使用原生InnerAudioContext。
- U03词条/音标20px，释义/原句16px，缺项独立隐藏；语块20/16px，空语块整区隐藏。U07删除指定旧说明、紧凑分组、48px行和28px退出间隔。U06三列等宽，数字与说明同轴居中。

## 后续发布与真机验收

本轮没有推送、合并或部署。发布时先由受控迁移流程将共享数据库扩展到0013，再更新管理API/Worker与小程序API，最后对应前端；两角色新代码的readiness最低要求0013。新增列可空或有默认值，保留历史发布JSON和素材。普通发布不批量转换历史素材；旧音频在编辑页明确处理后才可重新发布。回滚应用仍须使用既有受控发布流程，不能为了回滚而删除本批新增列或播放文件。

真机使用专门验收账号，iOS与Android各对四种上传来源处理后的音频执行五档实际播放、暂停继续、拖动、播完手动重播、词汇打断、译文/图片往返、收藏/完成、切卡、重试、退出/重启和调速失败；核对真实速率、原始时长/音高、无叠播和无额外学习计数。另验U07编辑/头像更新返回、隐私/退出及U06点击去向与窄屏长内容。
